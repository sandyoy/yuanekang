# 微信支付「特约商户」签约与合作说明
## 医院作为特约商户 · 与圆爱康（服务商）的分工与预期成果

> 致：合作医院 财务科 / 信息科 / 院办
> 说明：本文向院方说明——贵院作为微信支付的「特约商户」，圆爱康作为微信支付的「服务商」，双方签约合作后如何分工、各自做什么、最终能给贵院和患者带来什么样的退款体验。**本文为沟通说明稿，不构成正式合同**，正式权利义务以双方与微信支付/财付通签署的文件为准。

---

## 一、一句话讲清合作模式

> **贵院的钱、贵院的微信商户号、贵院的收款与品牌，一样不动；圆爱康作为微信支付官方认证的"服务商"，以一套系统替贵院自动办理"患者退款"，尤其是那些零散、高频、不想占用贵院财务时间的部分退款。**

打个比方：贵院的微信商户号 = 贵院的一张"收款卡"。圆爱康不是拿这张卡去花钱的人，而是**受贵院授权、拿着一张"只允许办退款"的授权牌**的人——替贵院把该退给患者的钱，**从贵院账户原路退回**给患者本人。卡在谁手里、钱归谁、对外显示谁的名字——**统统还是贵院的**。

## 二、两种身份，各是什么、各做什么

| | 医院＝**特约商户** | 圆爱康＝**服务商** |
|---|---|---|
| 身份本质 | 微信支付真正的**收款方/资金主人** | 微信支付官方认证的**技术+服务合作方** |
| 患者钱的归属 | ✅ 进**贵院自己的商户号**，结算到**贵院对公账户** | ❌ 不经手、不过账、不归属圆爱康 |
| 患者看到的收款方 | 贵院名称 | 平台机制上患者看不到圆爱康名字 |
| 核心职责 | 提供资质、拥有资金与品牌 | 用系统替贵院**自动办退款**等操作 |

---

## 三、医院（特约商户）要做什么——很轻、很边界清晰

医院不是"把账号交出去"，而是提供三样东西，权限始终可掌控：

| # | 医院要做的事 | 说明 | 医院的核心顾虑是否有保障 |
|---|------------|------|:---:|
| 1 | **以医院名义开通/确认微信商户号** | 已有则沿用门诊缴费那个即可 | ✅ 收款方永远是医院 |
| 2 | **提供进件资质** | 事业单位法人证书、医疗机构执业许可证、同名对公账户、法人身份证（由微信审核，不经圆爱康） | ✅ 资料不经过第三方 |
| 3 | **主动开通"服务商代调用"授权** | 这一步**由医院自己在微信商户平台后台点确认**，圆爱康无权代替医院点击；授权范围可书面锁死、可随时撤销 | ✅ 权限在贵院手里、可控 |

> 医院只需配合"开通商户号 + 提供资质 + 主动授权"，**不涉及把密钥、账户密码、提现权交给圆爱康**。授权可随时后台一键撤销。

---

## 四、圆爱康（服务商）要做什么——只做"退款动作"，绝不越界

### ✅ 圆爱康做的事情（都在授权范围内）
- 以服务商身份、通过**微信支付官方退款 API**，在**贵院商户号**上替贵院发起退款
- 退款金额**按"剩余未消费服务 × 约定单价"由系统自动核算**，不靠人拍脑袋，可全量对账、留痕可查
- 支持**全额退**和**部分退（退差额）**两种，均走 API 自动操作
- 按贵院要求输出退款对账报表，财务月底核对

### ❌ 圆爱康绝不做（权限边界书面锁死）
- 不动贵院的**提现 / 结算 / 转账 / 换绑账户**
- 不经手、不归集、不清分贵院的任何患者资金
- 不接触贵院商户号以外的经营数据（如 HIS、病历等）——只处理"这笔订单退多少"这一个动作

## 五、三方分工一览（谁出钱、谁出系统、谁出工具）

| 角色 | 钱/系统/资质上负责什么 |
|------|------------------------|
| **医院（特约商户）** | 出**资质与商户号**、出**患者资金**；拥有资金、品牌、对外责任主体 |
| **圆爱康（服务商）** | 出**系统与运营**：自动核算退款、调 API 发起退款、输出对账；不碰钱 |
| **微信支付/财付通（持牌方）** | 出**清算工具**：所有资金清分、退款原路划转由持牌财付通完成 |

## 六、合作后能达到的结果——以患者退款为例

以下三类退款，签约后都能由圆爱康系统**自动、快速、原路**替贵院办妥，贵院财务不必守着收银：

| 场景 | 操作 | 患者体验 | 贵院财务负担 |
|------|------|---------|:---:|
| **全额退款** | 系统自动对该订单发全额退款 | 原路退回，微信零钱即时到账、银行卡按原路 | 免人工、7×24h 自动 |
| **部分退款（退差额，如疗程做了3次剩7次）** | 系统按"剩余7次×单价"自动核算并退款 | 原路退回剩余部分，无需再向患者要账号 | 免人工、且金额有据可查 |
| **任何时间点退款** | 患者半夜/周末申请，系统自动响应 | 不等贵院财务上班，响应快、投诉少 | 完全解放 |

> **一句话成果**：以前"部分退差额"要财务人工盯、患者要等、还可能被质疑；签约后变成"系统按规则自动原路退、患者秒到钱、贵院月底看一张对账单"。

## 七、责任如何界定（院方最关心的，如实说明）

1. 微信支付官方现行规则：商户应妥善保管商户号、API 密钥/证书，因保管不善致损由商户承担；财付通根据商户指令处理退款，商户需对指令真实性负责。
2. 即：**每一笔退款的真实性、金额准确性、对外责任主体，始终是商户（贵院）**。微信支付允许在商户授权下由服务商系统代调用退款接口，**并未禁止**。
3. 圆爱康用两件事替贵院把风险关在笼子里：
   - **只退"算得出来"的金额**：退款必须由系统按"已购服务 + 剩余未消费"可核验记录自动计算，每笔有据可查；
   - **书面锁定授权边界**：以《授权范围说明》明确圆爱康仅被授权"按订单原路退款/部分退款"，不含提现、转账、换账户等敏感操作。

## 八、医院要走的流程（如院方有意向）

1. 院方确认是否已有微信商户号；若无，联系微信支付拓展(BD)确认公立医疗机构开户政策；
2. 圆爱康提供《服务商代调用授权范围说明》草稿供院方法务/财务审阅；
3. 圆爱康发起"特约商户进件"，院方提交资质并在线签约；
4. 双方联调、试点（建议先单个病种小范围试点跑一个月，全程可看对账单，验证满意再推开）。
