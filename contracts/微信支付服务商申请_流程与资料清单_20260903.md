# 圆爱康 申请微信支付服务商
## 操作流程 + 需提交资料清单（给技术/运营同事 · 明日开工版）

> 适用：圆爱康科技拟申请成为微信支付「服务商」，为后续合作医院（特约商户）提供自动化退款 / 分账能力。
> 依据：微信支付官方公开文档《服务商入驻指引》《服务商平台操作手册》（2024–2026）。
> 标注说明：【官方确定】= 官方公开固化流程；【需页面确认】= 以实际申请页为准。

---

## ⚠️ 全文最需要先记住的 3 件事

1. **申请服务商 = 免费 + 无保证金**。微信支付服务商只是"渠道合作伙伴/代理商"角色，**不需要像支付牌照那样提前押钱**。任何中介称"交 3–30 万才能开通"，**100% 与微信官方无关**（官方唯一客服 95017）。
2. **入驻只是第一步**，与"能帮医院退款"之间还有两层：① 每家医院单独进件为特约商户；② 开通并调用退款/分账 API。
3. **全程用电脑操作 + 法人/负责人微信扫码**。手机端只用于扫码确认。

---

## 一、操作顺序（第一步到第九步）

> ⚠️ 不存在"单独注册服务商"的入口——必须**先有普通商户号，再从商户平台升级为服务商**（2023 年后微信统一账号体系的规则）。

1. **注册商户号**：打开 pay.weixin.qq.com → 「接入微信支付/注册」→ 管理员微信扫码 → 填企业主体 → 提交营业执照 → 自动开通，拿到**商户号 mch_id**。（即时，无需人工）
2. **关联 AppID**：若公司已有小程序/公众号 AppID，在「产品中心 → AppID 账号管理」关联；若无，**建议先用公司资质注册一个小程序**（服务商后续很多操作要在 AppID 上下文里做）。
3. **进入服务商中心**：pay.weixin.qq.com 左侧菜单「服务商中心」→ 「申请成为服务商/服务商入驻」。
4. **填写服务商资质**：见下方资料清单。
5. **等待审核**（1–7 个工作日）。
6. **协议签署**：审核通过后，「账户中心→签约」在线签署《微信支付服务商合作协议》，另签《反洗钱承诺函》《清算服务协议》等配套文件。
7. **开通服务商功能**：「产品中心」自行勾选：特约商户进件、退款、分账等接口权限。
8. **设置服务商信息**：「服务商中心→服务商信息」完善客服电话、经营类目、服务区域。
9. **完成开发联调**：拿到 mch_id + APIv3 密钥 + 商户证书，技术开工。

## 二、需提前准备的资料清单（逐项核对）

| # | 资料名称 | 必要 | 形式要求 | 备注 |
|---|---------|:---:|---------|------|
| 1 | **营业执照（三证合一）** | ✅ | 原件彩色照片/扫描件，JPG/PNG，<2MB | ⚠️ **经营范围必须含"软件开发/技术咨询/技术服务/信息系统集成"任一**，这是最常见卡点 |
| 2 | **法人身份证** | ✅ | 正反面原件照片 | 需与营业执照法人一致、在有效期内 |
| 3 | **对公银行账户** | ✅ | 开户许可证/基本存款账户信息表 + 账号 | 账户名须与执照主体**一字不差** |
| 4 | **开户行信息** | ✅ | 精确到支行 | 填错拖慢结算 |
| 5 | **联系人信息** | ✅ | 姓名+手机+邮箱 | 建议留**技术负责人**，便于开发沟通 |
| 6 | **管理员微信** | ✅ | 已实名认证的个人微信 | 建议用**法人或总经理**微信，否则法人验证环节要补操作 |
| 7 | **经营类目** | ✅ | 下拉菜单选择 | ⚠️ 选「信息技术服务」下的「软件服务/技术服务」，**不要选"医疗"类目**（医疗是特约商户侧的事） |

**不必准备**：医疗相关资质（服务商角色不需要提交，医疗资质由医院侧提供）、公司门头照片（特约商户进件时才可能要）。

## 三、阶段与时长预估

| 阶段 | 操作 | 时长 |
|------|------|------|
| 前置准备 | 确认经营范围含技术服务；对公户开通；法人微信实名 | 1–3 工作日（若需工商变更经营范围约 3–7 工作日，广东线上可办） |
| 注册商户号 | pay.weixin.qq.com 提交执照 | 即时 |
| 服务商资质审核 | 交法人身份证、对公账户等 | 1–7 工作日（多数 2–3）；⚠️ 会向对公户打一笔**随机小额验证款(0.01–1元)**，需页面回填金额 |
| 协议签署 | 在线签《服务商合作协议》等 | 即时（扫码+短信） |
| 功能开通 | 勾选各 API 权限 | 即时 |
| 开发联调 | 配 APIv3 密钥、证书、回调 | 技术侧 3–10 工作日 |

**合计：从开工到服务商身份完全可用，通常 5–15 个工作日**（不含可能的前置工商变更）。

## 四、服务商 ≠ 最终目标：和中"医院/退款"的关系

```
当前目标                         后续目标
① 成为微信服务商      →     ② 每家医院单独"特约商户进件"（一院一签、独立审核）
                          →     ③ 开通并调用 退款 API / 分账 API（服务商代特约商户操作）
```

- **每家合作医院都要单独走一次"特约商户进件"**，提交医院资质（医院走事业单位/医疗机构类目需《事业单位法人证书》《医疗机构执业许可证》）。
- 医院进件成功、拿到自己的特约商户号后，圆爱康才能以服务商身份为它调 **退款 API（fund/refund）** 和 **分账 API（profitsharing）**。
- ⚠️ 进件时最好给该医院勾选"分账功能"并配置比例；医疗类目交易分账可能有额外风控，**建议提前联系微信支付 BD 报备"医疗场景+分账"**（95017 转服务商线），别等系统触发风控。
- **"能退款"顺序**：圆爱康先成服务商 → 医院成为特约商户 → 再谈自动化退款开发。当前文档只覆盖第①步。

## 五、💰 到底要不要交钱？（重点，别再被"保证金/资本金"绕晕）

| 项目 | 金额 | 说明 |
|------|:---:|------|
| 服务商入驻申请费 | **¥0** | 官方不收任何入驻费【官方确定】 |
| 保证金/押金 | **¥0** | 微信服务商**无保证金制度**，不需预存资金【官方确定】 |
| 年费/管理费 | **¥0** | 目前无服务商年费（以最新公告为准） |
| API 调用费 | **¥0** | 退款、分账接口本身不收费 |
| 交易手续费 | 约 0.2%–0.6% | 不是入驻费，是每笔交易从**医院(特约商户)侧**扣的支付手续费，与微信 BD 确认具体费率 |
| 分账手续费 | 0–1% | 计入交易手续费，需页面确认 |

> **⚠️ 辨清两个概念**：
> - **"资本金/注册资本"** = 执照上公司股本数字，**不用存钱进账户**（是支付牌照才要实缴上亿，圆爱康不是做支付牌照）。圆爱康资本金够，此项无忧。
> - **"保证金"** = 微信服务商**无此制度**，任何"交钱才开通"都是骗局/代办中介话术。

## 六、常见被拒/卡住点（逐条排查）

| # | 原因 | 解决 |
|---|------|------|
| 1 | 执照经营范围不含"软件开发/技术服务" | 先做工商变更（广东线上约 1–3 工作日） |
| 2 | 对公账户信息不符（开户名≠执照主体等） | 核对基本户开户许可证，开户名全称一字不差 |
| 3 | 法人身份证过期/模糊/与执照不符 | 确保证件有效、拍照无反光四角完整 |
| 4 | 管理员微信非法人、无法完成法人验证 | 建议直接用**法人微信**注册 |
| 5 | 误选"医疗"类目被风控 | 服务商类目选「信息技术服务」，医疗由医院侧提交 |

**容易卡住但不算被拒**：对公验证款超3工作日未到账（联系银行）；页面提示"该主体已注册"（可能被某 SaaS 用同一主体注册过，联系 95017 解绑）；商户号被关联其他服务商（需联系原服务商解绑）。

## 七、明日（第 1 天）开工执行清单 ACTION ITEM

- [ ] **行政/法务确认营业执照经营范围**含不含"软件开发/技术服务/技术咨询"；不含 → 立即启动工商变更
- [ ] 确认**对公账户**已开通、能收款（收微信验证款）
- [ ] **法人**备好身份证原件 + 本人已实名微信
- [ ] 备好**联系人**（建议技术负责人）姓名/手机/邮箱
- [ ] 注册/确认一个小程序 AppID（企业主体；有则跳过）
- [ ] 上 pay.weixin.qq.com → 注册**微信支付商户号**（提交执照，即时通过）
- [ ] 商户平台 → 「服务商中心」→ 发起**服务商入驻申请**

**第 2–5 天**：跟进审核(1–7工作日) → 回填对公验证款 → 法人微信扫码签协议 → 配 APIv3 密钥/证书 → 勾选进件/退款/分账权限 → 跑通接口连通性测试。
**第 6 天起（并行）**：联系微信 BD 报备"医疗+分账"；联系第一家医院收集进件材料（执照/事业单位法人证书/开户许可证/法人身份证/联系人）；发起医院特约商户进件。
