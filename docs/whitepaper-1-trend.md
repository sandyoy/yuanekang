# 从院内到居家：数字康复的实践之路
## 基于珠海妇幼保健院4年运营数据的研究报告

**出品：圆爱康生物科技有限公司**
**2026年5月**

## 摘要

本报告基于珠海妇幼保健院2021年12月至2026年4月的49,555条院内订单和2,949条居家康复订单数据，系统分析了"院内诊疗+居家康复"模式的可行性和价值。研究发现：居家康复业务不但没有分流院内业务，反而通过提升患者依从性和满意度，带动院内业务同步增长。更值得关注的是，这一模式实现了医院**零成本启动**——无需投入任何设备和耗材。

## 一、行业背景：康复医疗的困境与转机

### 1.1 康复医疗需求爆发，但供给严重不足

- 老龄化加速、慢性病高发、术后康复需求持续增长
- 中国康复医疗市场规模预计2025年突破2,000亿元
- 然而康复医师缺口大、设备投入高、患者依从性低

### 1.2 传统康复模式的三大痛点

**瓶颈一：设备投入大，医院负担重**
- 一台盆底康复治疗仪采购价数十万元
- 磁刺激、射频等高端设备更达百万级别
- 科室预算有限，设备更新慢

**瓶颈二：患者出院即失联，依从性差**
- 患者在医院做完治疗回家后，缺乏持续指导和监督
- 康复是一个周期性的过程，中断治疗严重影响效果
- 据行业统计，院外康复依从率不足40%

**瓶颈三：科室收入增长缓慢**
- 受床位和设备限制，每日接诊量存在天花板
- 患者复诊率低，存量客户持续流失
- 缺乏新的收入增长点

### 1.3 数字疗法与居家康复成为破局方向

政策层面，国家卫健委多次发文鼓励"互联网+康复医疗"、"居家康复"等服务模式。技术层面，智能可穿戴设备、远程监测、AI辅助评估等技术的成熟，使居家康复从概念走向现实。

## 三、核心发现一：居家≠替代院内，而是增量互补

### 3.1 两者同步增长，不存在此消彼长

如果居家康复"抢走"了院内的患者，我们应该看到：居家增长的同时，院内下降。但实际数据恰恰相反——

| 年份 | 院内订单 | 居家订单 | 合计 |
|:---:|:-------:|:--------:|:---:|
| 2022 | 10,068 | 未上线 | 10,068 |
| 2023 | 9,950 | 未上线 | 9,950 |
| 2024 | 10,504 | 579 | 11,083 |
| 2025 | 14,077 | 1,551 | **15,628** |

居家上线的2024年，院内不仅没有减少，反而从9,950增长到10,504。2025年居家翻倍增长的同时，院内也增长了34%达到14,077。

**结论：居家康复不是在分蛋糕，而是在把蛋糕做大。**

### 3.2 背后的逻辑

**患者路径变化：**
```
传统路径：
    院内治疗 → 回家 → 失联 → 不复诊

居家路径：
    院内治疗 → 居家续疗（六师共管）→ 效果好 → 回院复查/续费
```

1. **依从性提升**：患者在医院做完治疗后，回家通过居家设备继续康复，六师共管团队持续跟踪指导，完成率大幅提升
2. **满意度驱动复购**：居家效果好 → 患者对医院信任度提高 → 更愿意回院做更高阶的治疗
3. **口碑裂变**：效果真实可见 → 患者自发发帖 → 带来新患者

## 五、模式拆解：居家康复如何落地

### 5.1 标准化启动流程

**第一阶段：启动（圆爱康主推）**
```
① 品牌部进场 → 物料布置 + 招募现场美陈
② 与医生共同筛选患者（挑确定有效果的）
③ 第一批10位患者免费治疗
④ 每做1次发1篇真实打卡帖（10人×6次=60篇内容）
```

**第二阶段：自运转（医院主导）**
```
⑤ 科室护士学会标准化评估→治疗流程
⑥ 医院自行定期招募（常德市一已做到第3期）
⑦ 医生个人自媒体同步发布（如江主任小红书放号）
⑧ 患者自发传播 → 形成飞轮效应
```

### 5.2 内容策略

圆爱康的内容策略与传统医疗营销有本质区别：

| 传统医疗广告 | 圆爱康内容策略 |
|:-----------|:--------------|
| 明星/网红代言 | **真实患者**打卡 |
| 专业术语堆砌 | **消费行为展示**（打1次什么效果→打3次什么效果） |
| 单次投放 | **持续内容流**（来一个发一个） |
| 品牌自说自话 | **第三方真实口碑** |

**效果**：做得好的医院在小红书和视频号上都能搜到大量真实患者帖，形成持续的内容资产。

## 七、未来展望

### 7.1 从单点到全国复制

珠海妇幼的验证表明，这一模式具备极强的可复制性。下一步的重点是：
- 将珠海妇幼的经验提炼为标准操作手册
- 通过省区联动，将模式复制到更多医院
- 常德市一等标杆医院的实践已初步验证了跨区域复制的可行性

### 7.2 从产后康复到多病种覆盖

当前居家业务以子宫复旧（66%）为核心，未来可拓展到：
- 心脏术后康复
- 儿童ADHD注意力训练
- 阿尔兹海默症认知训练
- 骨科关节置换术后康复

### 7.3 从医院合作到社区健康驿站

结合旗下家家健健康管理研究中心的社区资源，探索"社区食堂+健康角"模式——将居家康复的触角延伸到社区，实现"医院→居家→社区"三级覆盖。
