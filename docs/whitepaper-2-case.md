# 医院居家康复项目合作案例
## 圆爱康 × 珠海妇幼保健院

**合作模式｜落地流程｜效果数据｜合作价值**

## 一、合作背景

珠海妇幼保健院是圆爱康核心合作医院之一。双方的合作始于2021年底，从最初的院内盆底康复治疗逐步拓展到居家康复领域。

**合作前医院的痛点：**
- 盆底/产后康复需求量大，但设备有限，接诊量存在天花板
- 患者在医院做完治疗后回家无人跟进，依从性差
- 科室收入增长遇到瓶颈，急需新的增长点
- 医院自购康复设备需投入数十万至上百万，预算紧张

**圆爱康的解决方案：**
以"零成本启动"的方式，为医院提供完整的居家康复解决方案——包括设备、平台、运营、培训、六师共管全链条服务。

## 二、合作模式

### 核心逻辑

```
圆爱康         ↓ 提供设备 + 平台 + 运营 + 六师共管
医院           ↓ 提供场地 + 患者 + 医护
患者           ↓ 院内治疗 → 居家续疗
三方共赢       ↓ 效果好 → 口碑传播 → 更多患者来
```

### 合作框架

| 角色 | 投入 | 产出 |
|:----|:----|:----|
| **医院** | 场地、医护人力 | 院内收入增长 + 居家分成 + 患者满意度提升 |
| **圆爱康** | 设备、平台、运营团队、六师共管 | 服务费收入 |
| **患者** | 治疗费用 | 专业康复服务，院内外无缝衔接 |

## 三、落地流程

### 步骤1：启动准备（圆爱康品牌部进场）

圆爱康品牌部团队进驻医院科室，完成：
- **物料布置**：招募现场的宣传海报、展架、科普资料
- **空间美陈**：打造有吸引力的招募环境
- **医生沟通**：明确筛选标准——挑"确定会有效果"的患者作为第一批种子用户

### 步骤2：患者招募与筛选

- 由医院通过现有患者渠道发布招募信息
- 圆爱康产品经理与医生共同评估、筛选
- **第一批招募10位患者**，提供免费治疗
- 入选标准：病理明确、预期效果好、愿意配合分享

### 步骤3：标准化治疗

- 患者在医院完成初次评估和治疗方案制定
- 转入居家康复阶段，使用圆爱康居家设备+平台
- 六师共管团队持续跟踪：康复进度、设备使用、问题解答
- **标准化SOP**：评估→治疗→追踪→反馈，每个环节有标准操作流程

### 步骤4：内容生产

每位患者治疗期间，按标准流程产出真实内容：
- **每做1次发1篇**：打1次什么效果？打3次什么效果？
- **素人探店式打卡**：非网红/非明星，真实患者第一视角
- **双平台分发**：小红书 + 视频号
- **规模化**：1人做6次=6篇，10人=60篇，持续产出

### 步骤5：医院自运转

- 圆爱康产品经理教会科室护士标准化评估→治疗流程
- 教会后护士自行操作，圆爱康团队仅需定期盯一下
- 医院可自行组织后续招募活动
- **典型案例**：常德市一已做到第3期患者招募，完全由医院主导

### 步骤6：医生个人IP联动

- 科室医生注册个人小红书/视频号账号
- 定期放号引流（如江主任每周放号600元门诊）
- 与医院官方账号形成矩阵，扩大传播覆盖面

## 五、核心结论

### 结论一：居家康复为医院创造增量，而非替代院内业务

上线居家业务后，院内订单同步增长：

> 2025年居家增长+168%，院内同步增长+34%
>
> "居家+院内"合计年订单突破15,000单，创历史新高

居家康复不是分走医院的蛋糕，而是把蛋糕做大。

### 结论二：医院零成本启动，无任何设备投入风险

传统模式下，医院开展康复项目需要：
- 采购设备：30万~100万+
- 采购耗材：持续成本
- 组建团队：人力成本

圆爱康模式下：
- 设备全由圆爱康提供
- 耗材全由圆爱康提供
- 六师共管团队由圆爱康负责
- 医院只需提供场地和医护人力

**医院做居家康复，零成本、零风险。**

### 结论三：标准化流程确保可复制

整个合作流程已形成标准化SOP，可快速复制到其他科室和其他医院：
1. 品牌部进场 → 物料+美陈
2. 筛选种子患者 → 免费治疗换内容
3. 培养科室护士 → 教会标准化流程
4. 医院自运转 → 定期招募活动

## 七、常见问题

**Q：居家康复会不会影响院内的业务量？**
A：不会。从实际数据看，居家业务上线后院内业务同步增长，两者是互补关系而非替代关系。

**Q：居家康复的效果有保障吗？**
A：有。圆爱康六师共管团队提供全程跟踪指导，确保患者按照标准化方案完成康复。同时，项目筛选机制确保首批患者为"确定有效果"的种子用户，保证初期口碑。

**Q：医院需要投入什么？**
A：医院只需提供场地和医护人力。所有设备、耗材、运营、管理团队均由圆爱康提供。

**Q：患者从哪里来？**
A：首批患者由医院现有患者池招募，圆爱康品牌部配合筛选。后续通过真实患者在小红书/视频号上的自发传播，持续吸引新患者。
